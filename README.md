# 辩论赛计时器（三人制 · 网页版）

一个为高校研究生辩论赛设计的**单文件网页计时器**：主控端 + 投影副屏双端一体，电脑、手机浏览器打开即用，支持离线运行，数据保存在本地。

- 规则基准：《关于举办第九届湖南省高校研究生辩论赛的通知》附件 1（湖南赛区赛制规则）
- 开源地址：<https://github.com/zxq360/Debate-timer>
- 当前版本：v1.1.5

---

## 功能特性

### 计时核心
- 完整五环节赛制：**开篇立论 → 攻辩 → 攻辩小结 → 自由辩论 → 结辩陈词**，按通知规则预置时长与灯态提醒
- 普通环节自动切段（共 14 段），攻辩 8 段按「正攻反辩 / 反攻正辩」固定顺序走
- 自由辩论双钟独立计时、互不影响，反方先发言
- 黄灯提醒、红灯停表，灯态下整屏（含投影）变警示色
- 上一段 / 下一段 / 开始暂停 / ±10 秒微调 / 重置本段

### 投影副屏
- 主控一键打开投影窗口（超大字号、自动暗色遮罩保证清晰）
- 主控的一切改动（队名、时长、外观、校徽、环节切换、计时状态）**实时同步**到已打开的投影，无需刷新
- 支持自由辩论双半屏大校徽布局
- 手机与电脑在同一 WiFi 下即可互投

### 外观与校徽
- 背景设置：红金盛典（默认，内嵌校方红金背景图）/ 正红纯色 / 暖纸白 / 墨韵黑
- 界面字体：黑体 / 宋体 / 楷体；界面字号：标准 / 大 / 特大（主控全部元素等比缩放，投影时间数字同步放大）
- 计时数字颜色：主控、投影各一个取色器 + 快捷色板，黄红灯时自动让位警示色
- 高校校徽：正反方各上传一枚，自动居中裁剪压缩为 128px 圆形，主控与投影全部展示位同步

### 提醒铃声
- 四种系统自带铃声（经典 / 叮声 / 叮咚 / 铃音，Web Audio 合成、零音频文件），三档音量可调
- 支持上传自定义铃声（mp3 / wav / m4a / ogg，限 500KB 内，以 dataURL 保存在本机），可试听、可一键清除回退
- 黄灯响一遍、红灯连响三遍；设置中点「试听铃声」可即时预览，选「自定义」但未上传时自动回退经典音

### 引导与帮助
- 新手引导：打开时询问是否进入分步引导（可「不再提示」，可在关于中重新开启）
- 页面问号「？」：点击查看当前页面的使用说明（普通计时页 / 自由辩论页 / 设置页各有对应文案）
- 环节规则「！」：点击查看当前环节的规则说明，默认取自通知 PDF，可在设置中编辑并恢复默认
- 关于：作者信息、开源链接、关注 / 收藏 / 建议引导

### 工程特性
- **单文件**：整个应用只有一个 `index.html`，零第三方依赖、零联网请求，拷到 U 盘即可用
- 设置与校徽存于浏览器 `localStorage`，关掉再开不丢
- 触控友好：按钮不小于 44px，375px 手机窄屏无横向溢出

## 快速开始

### 电脑端
1. 用 Chrome / Edge 打开 `index.html`，即为主控界面。
2. 点击顶栏「投影副屏」弹出投影窗口（地址自动带 `?projector=1`），把投影窗口拖到投影仪或外接屏。
3. 主控上一切操作（开始、切段、改设置、换校徽）投影实时跟随。

### 手机 + 电脑同 WiFi
1. 手机打开 `index.html` 作为主控。
2. 在手机顶栏点「投影副屏」→ 用电脑浏览器打开弹出的地址（或手动在电脑访问 `index.html?projector=1`）。
3. 手机控制计时，电脑投影展示。

> 提示：投影页无任何操作按钮，只负责展示；全屏可点顶栏「全屏」或按 `F11`。

## 操作说明

| 区域 | 功能 |
| --- | --- |
| 顶栏 | 正反方队名（含校徽）、投影副屏、全屏、帮助「？」、关于「ⓘ」、设置 |
| 环节导航 | 五个环节 Tab，点击切换；自由辩论进入双钟视图 |
| 计时卡片 | 当前段信息、倒计时表盘、剩余规则提示、规则「！」按钮 |
| 底部控制条 | 上一段 / 开始暂停 / 下一段 / −10 秒 / +10 秒 / 重置本段 |
| 设置抽屉 | 队伍名称、高校校徽、环节时长、背景与字体外观、环节规则、提醒铃声、提醒与操作、恢复默认 |

### 新手引导
- 每次打开主控时询问是否开始引导；选择「不再提示」后不再询问（可在「关于」中重新开启）。
- 引导以高亮 + 气泡分步指出关键区域，中途点遮罩或按 `Esc` 可退出。

### 设置说明
- **环节时长**：默认锁定赛事规则，可按需修改（分:秒格式）。
- **环节规则**：五个环节的规则文案默认取自通知 PDF，可编辑、可一键恢复 PDF 默认。
- **提醒铃声**：四种系统铃声与三档音量可选；「上传自定义铃声」读取本机音频（≤500KB），「试听铃声」预览当前选择，「清除自定义」回到系统音。
- **恢复赛事规则默认**：重置全部时长、外观、铃声与校徽。

## 赛制规则（默认值，取自通知附件 1）

| 环节 | 时长 | 黄灯提醒 | 说明 |
| --- | --- | --- | --- |
| 开篇立论 | 3:00 / 段 | 剩余 0:30 | 正方一辩先，共 2 段 |
| 攻辩 | 攻 1:00 / 辩 1:30 | 剩余 0:15 | 共 8 段，正方先攻，正攻反辩 / 反攻正辩交替 |
| 攻辩小结 | 1:30 / 段 | 剩余 0:30 | 正方先，共 2 段 |
| 自由辩论 | 双方各 5:00 | 仅红灯 | 反方先发言，双钟独立 |
| 结辩陈词 | 4:00 / 段 | 剩余 0:30 | 反方三辩先，共 2 段 |

> 规则全文可在页面「环节规则」弹窗中查看，并可在设置中编辑。

## 技术说明

- 原生 HTML / CSS / JavaScript（严格模式 IIFE），无任何框架与外部库
- 主控与投影同步：`BroadcastChannel` + `storage` 事件双通道 + 快照兜底
- 设置持久化：`localStorage`（键 `debate-timer-settings-v1`）
- 校徽处理：Canvas 居中裁正方形 → 压缩至 128px → dataURL 内联，体积自动控制
- 系统铃声：Web Audio Oscillator 合成音序，无音频文件；自定义铃声以 dataURL 存入 localStorage（≤500KB）
- 投影窗口识别：URL 参数 `?projector=1`
