# 辩论赛计时器（网页版）

为三人制高校研究生辩论赛设计的计时工具，打开网页即可使用，手机、电脑与投影副屏通用。

- **当前版本：v1.2.6**
- 规则基准：《关于举办第九届湖南省高校研究生辩论赛的通知》附件 1
- 开源地址：<https://github.com/zxq360/Debate-timer>
- 开发者邮箱：zxq2333@qq.com

---

## 功能特性

### 计时核心

- 完整五环节赛制：**开篇立论 → 攻辩 → 攻辩小结 → 自由辩论 → 结辩陈词**，各环节时长与灯态预置为通知规则。
- **开篇立论 / 攻辩小结 / 结辩陈词**：单环倒计时，按正方、反方顺序自动分段，剩余 30 秒亮黄灯、到点亮红灯。
- **攻辩**：两轮四次分开计时（正二提问、反二提问、正三提问、反三提问），每次提问方（攻）1:00、被提问方（辩）1:30，双方两个累计钟、谁发言走谁的表，剩余 15 秒亮黄灯；一方到点自动切换另一方继续，可随时切换任意一次。
- **自由辩论**：双方各累计 5 分钟，从反方开始，点对方表盘即切换发言方，某方到 5 分钟锁定并自动由另一方继续。
- 开始 / 暂停、上一段（次）/ 下一段（次）、±10 秒微调、重置本段（本环节 / 本次）、自动进入下一段。

### 投影副屏

- 主控一键打开投影窗口（`?projector=1`，超大字号、暗色遮罩保证清晰）。
- 主控的一切改动（队名、时长、外观、校徽、环节切换、计时状态）**实时同步**到已打开的投影。
- 普通环节整屏大表盘，自由辩论 / 攻辩左右双半屏，攻辩顶部显示当前轮次名。
- 手机与电脑在同一 WiFi 下即可互投。

### 外观与校徽

- 背景设置：红金盛典（默认）/ 正红纯色 / 暖纸白 / 墨韵黑。
- 界面字体：黑体 / 宋体 / 楷体；界面字号：标准 / 大 / 特大（主控全部元素等比缩放，投影时间数字同步放大）。
- 计时数字颜色：主控、投影各一个取色器 + 快捷色板，黄红灯时自动让位警示色。
- 高校校徽：正反方各上传一枚，自动居中裁剪压缩为 128px 圆形，主控与投影全部展示位同步。

### 提醒铃声

- 四种系统自带铃声（经典 / 叮声 / 叮咚 / 铃音，Web Audio 合成、零音频文件），三档音量可调。
- 支持上传自定义铃声（mp3 / wav / m4a / ogg，限 500KB 内，以 dataURL 保存在本机），可试听、可一键清除回退。
- 黄灯响一遍、红灯连响三遍；设置中点「试听铃声」可即时预览。

### 引导与帮助

- 新手引导：打开时询问，确认后先展示「关于」再进入分步高亮引导，光标准确定位，自适应宽屏 / 窄屏 / 字号缩放。
- 页面问号「？」：点击查看当前页面的使用说明（普通计时页 / 攻辩页 / 自由辩论页 / 设置页各有对应文案）。
- 环节规则「！规则」：各计时页统一入口，点击查看当前环节规则，**默认逐字取自通知 PDF 原文**，可在设置中编辑并一键恢复默认。
- 关于：版本与作者信息、开源链接、开发者邮箱、关注 / 收藏 / 建议引导，以及校内使用声明。

### 工程特性

- **单文件**：整个应用只有一个 `index.html`，零第三方依赖、零联网请求，拷到 U 盘即可用。
- 设置与校徽存于浏览器 `localStorage`（键 `debate-timer-settings-v1`），不上传任何数据。
- 触控友好：按钮不小于 44px，375px 手机窄屏无横向溢出。

## 赛制流程（三人制）

| 环节 | 顺序与时长 | 黄灯提醒 |
| --- | --- | --- |
| 开篇立论 | 正方一辩 3:00 → 反方一辩 3:00 | 剩余 30 秒 |
| 攻辩 | 两轮四次，共 10 分钟：正二提问（正攻 1:00 / 反辩 1:30）→ 反二提问（反攻 1:00 / 正辩 1:30）→ 正三提问（正攻 1:00 / 反辩 1:30）→ 反三提问（反攻 1:00 / 正辩 1:30） | 剩余 15 秒 |
| 攻辩小结 | 正方一辩 1:30 → 反方一辩 1:30 | 剩余 30 秒 |
| 自由辩论 | 双方各累计 5:00，从反方开始，分开计时 | 到点亮红灯 |
| 结辩陈词 | 反方四辩 4:00 → 正方四辩 4:00 | 剩余 30 秒 |

> 攻辩中提问方（攻）先发言，被提问方可自行确定二辩或三辩应对；计时页只显示「正方应对 / 反方应对」。

## 快速开始

### 电脑端

1. 用 Chrome / Edge 打开 `index.html`，即为主控界面。
2. 点击顶栏「投影副屏」弹出投影窗口（地址自动带 `?projector=1`），把投影窗口拖到投影仪或外接屏。
3. 主控上一切操作（开始、切段、改设置、换校徽）投影实时跟随。

### 手机 + 电脑同 WiFi

1. 手机打开 `index.html` 作为主控。
2. 在手机顶栏点「投影副屏」→ 用电脑浏览器打开弹出的地址（或手动在电脑访问 `index.html?projector=1`）。
3. 手机控制计时，电脑投影展示。

> 投影页无任何操作按钮，只负责展示；全屏可点顶栏「全屏」或按 `F11`。

## 操作说明

| 区域 | 功能 |
| --- | --- |
| 顶栏 | 正反方队名（含校徽）、投影副屏、全屏、帮助「？」、关于「ⓘ」、设置 |
| 环节导航 | 五个环节的 Tab，点击切换；攻辩下方有四次轮次条 |
| 计时卡片 | 当前段信息、倒计时表盘，下方「！规则」查看本环节原文规则 |
| 底部控制条 | 上一段（次）/ 开始暂停 / 下一段（次）/ ±10 秒微调 / 切换发言方 / 重置 |
| 设置抽屉 | 队伍与校徽 / 环节时长 / 背景字体颜色 / 铃声 / 环节规则 / 提醒与操作 / 恢复默认 |

### 设置说明

- **队伍名称 / 高校校徽**：修改正反方队名，上传正方形或透明底 PNG 校徽（自动压缩为圆形）。
- **环节时长**：默认锁定赛事规则，可按需修改各环节时长（分:秒）。
- **背景与字体外观**：背景主题、界面字体、字号缩放、主控 / 投影计时数字颜色。
- **提醒铃声**：四种系统铃声 + 音量调节，或上传 500KB 内自定义音频，可试听。
- **环节规则**：编辑各环节规则文案，或一键恢复通知 PDF 默认原文。
- **提醒与操作**：声音、震动、自动下一段、屏幕常亮开关。
- **恢复赛事规则默认**：重置全部设置（队名、校徽、时长、外观、铃声、规则）。

## 技术说明

- 原生 HTML / CSS / JavaScript（严格模式 IIFE），无任何框架与外部库。
- 计时核心：`state.endAt = Date.now() + remain`，主循环用 `requestAnimationFrame` + 时间戳差值，抗后台漂移。
- 主控与投影同步：`BroadcastChannel` + `storage` 事件双通道 + localStorage 快照兜底。
- 设置持久化：`localStorage`（键 `debate-timer-settings-v1`）。
- 校徽处理：Canvas 居中裁正方形 → 压缩至 128px → dataURL 内联，体积自动控制。
- 系统铃声：Web Audio Oscillator 合成音序，无音频文件；自定义铃声以 dataURL 存入 localStorage（≤500KB）。
- 投影窗口识别：URL 参数 `?projector=1`。
