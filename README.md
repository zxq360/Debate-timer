# 辩论赛计时器

面向高校辩论赛的单文件赛场计时工具，打开网页即可使用，支持主控屏与投影副屏双屏联动。

- **当前版本：v2.9.6**
- 内置环节结构与时长为**通用预设**（三人制五环节），请依据所在赛事的实际规则自行核对调整
- 开源地址：<https://github.com/zxq360/Debate-timer>
- 开发者邮箱：zxq2333@qq.com
- 许可协议：MIT License

## 功能特性

### 计时核心

- 完整五环节赛制：**开篇立论 → 攻辩 → 攻辩小结 → 自由辩论 → 结辩陈词**，各环节时长与灯态均有预置默认值。
- **开篇立论 / 攻辩小结 / 结辩陈词**：单环倒计时，按正方、反方顺序自动分段，亮黄灯、到点亮红灯；默认黄灯时点为立论剩 30 秒、攻辩小结剩 60 秒、结辩剩 30 秒。
- **攻辩**：两轮四次分开计时（正二提问、反二提问、正三提问、反三提问），每次提问方（攻）1:00、被提问方（辩）1:30，双方两个累计钟、谁发言走谁的表，剩 15 秒亮黄灯；一方到点自动切换另一方继续，可随时切换任意一次。
- **自由辩论**：双方各累计 5 分钟，从反方开始，点对方表盘即切换发言方，某方到 5 分钟锁定并自动由另一方继续。
- 开始 / 暂停、上一段（次）/ 下一段（次）、±10 秒微调、重置本段（本环节 / 本次）、自动进入下一段。
- **环节管理**：环节 → 小环节 → 计时器三级结构，可增删环节与小节、改名、启停、上下移动；每个小环节可选 1 个钟（双方串行，出场顺序可选正→反 / 反→正 / 仅某方）或 2 个钟（两个独立钟、各自填时长、指定谁先开始，自动交接轮走）。
- **黄灯提醒可逐个开关**：设置 → 环节时长里对立论 / 攻辩 / 小结 / 结辩各有一个「启用」开关；环节管理里每个计时器还各有自己的开关。关掉后该环节只在时间到时亮红灯，重新开启会恢复关闭前的秒数。

### 投影副屏

- 主控一键打开投影窗口（`?projector=1`，超大字号、暗色遮罩保证清晰），可选择是否显示摆放说明。
- 主控的一切改动（队名、时长、外观、校徽、环节切换、计时状态）**实时同步**到已打开的投影。
- **表盘精确居中**于可用区域，隐藏上方元素时自动重新居中，不会因状态文字占位而偏位。
- **普通环节**为整屏大表盘；**自由辩论 / 攻辩**为左右双表盘（与主控同款）：队名与校徽在表盘上方，环形进度圈内是大号倒计时，圈下是状态文字与一条进度条；攻辩顶部另起一行显示当前轮次名。两种表盘的数字字号、字重、斜体风格完全一致，字号档位（90%–200%）同步生效。
- 双表盘的表盘形态跟随「投影表盘样式」设置（环形 / 方形 / 圆点 / 无表盘），进度环实时反映剩余比例。
- **七个元素显隐开关**（顶部发言者与环节名、队名牌、双方辩题、VS 分隔、倒计时表盘、状态文字、进度条）：关掉某项后该元素不显示、其余自动重新居中，可组合出「只看时间」等版面。
- **布局预设**：横向（队名左右分列，默认）/ 纵向（队名上下分列，适合竖屏投影）/ 自由（可拖动队名条、倒计时、发言者行与进度条，双击元素复位，位置按百分比保存并同步副屏）。
- 副屏与主控需在同一台电脑的同一浏览器内（详见下方「关于跨设备」）。

### 辩题与队伍显示

- **正反方各一个辩题**：在「设置 → 辩题与队伍」中分别填写，投影副屏与主控顶栏同步显示。
- **投影顶部布局**（自上而下三层，主次分明）：环节名独占一行左对齐 → 队名左右对半的连续色条（正方蓝、反方紫，中间无缝）→ 正反方辩题另起一行分列 → 倒计时。
  四套背景各配一套投影色值，均实测 WCAG 对比度 ≥4.5:1。
- **主控顶栏**同样左右分列，正方卡带蓝边、反方卡带紫边。
- 某一方辩题留空则只显示其队名；双方都留空则整块隐藏，不占位置。
- **无校徽即不显示**：未上传校徽时不显示任何占位图案，也不会取队名首字生成字母牌。

### 外观与背景

- 预置背景：红金盛典（默认）/ 正红纯色 / 暖纸白 / 墨韵黑。
- **自定义背景**：可「上传原图到浏览器」（IndexedDB 二进制直存、零损失）或「保存到本地文件夹」（自动命名 `debate-bg_名称_日期.jpg`，与 HTML 同目录以 CSS 引用）；两者都不可用时自动降级为压缩到1920px 保底。背景列表可应用、改名（外部文件模式同时改文件名）、删除，并显示尺寸、体积与存储位置；「重新选择本地图片」可手动指定任意本地图片。设置项只存指针不存图片，因此配置存档不会因背景而膨胀；投影副屏自动使用同一背景。
- 界面字体：黑体 / 宋体 / 楷体；界面字号：标准 / 大 / 特大（主控全部元素等比缩放）。
- 主控表盘样式：环形 / 方形 / 圆点阵列 / 无表盘；主控数字字形：等宽 / 方正黑体 / 数码管 / 跟随界面；主控数字格式：简洁 3:00 / 精确 3:00.0。
- 计时数字颜色：主控、投影各一个取色器 + 快捷色板，黄红灯时自动让位警示色。

### 投影数字与进度条

- 投影拥有**独立于主控**的外观设置：表盘样式（环形 / 方形 / 圆点 / 无表盘）、数字字形（斜体记分牌 / 等宽 / 黑体 / 数字管 / 衬线 / 跟随界面）、数字格式（分:秒 / 厘秒 / 毫秒）、字号放大（90%–200%）、计时颜色。
- **斜体记分牌**（投影默认）：`Arial Black` + 12 度斜切的赛事记分牌风格，斜切只作用于数字本身，圆环表盘不被拉歪。
- 投影默认字号 150%。
- **进度条紧贴数字下方**（挂在表盘内部随表盘移动），不再悬在屏幕底部遮挡背景；隐藏上方元素时自动上移。

### 提醒铃声

- 四种系统自带铃声（经典 / 叮声 / 叮咚 / 铃音，Web Audio 合成、零音频文件），三档音量可调。
- 支持上传自定义铃声（mp3 / wav / m4a / ogg，限 500KB 内，以 dataURL 保存在本机），可试听、可一键清除回退。
- 声音总开关 + 黄灯 / 红灯独立开关；**响铃次数 0–10 次、响铃间隔 0.1–3.0 秒均可调，次数设为 0 即该项不响**；默认黄灯 1 次、红灯 3 次。
- 另有手机震动提醒开关（不受次数与间隔影响）。
- 设置中点「试听铃声」可即时预览。

### 键盘快捷键

**12 项**默认键位，可在「设置 → 键盘快捷键」中逐项改键、单独清除或一键恢复默认，并支持总开关。

| 功能 | 默认键 | 备注 |
| --- | --- | --- |
| 开始 / 暂停 | `空格` | 不会触发页面滚动 |
| 上一段 / 下一段 | `←` / `→` | 攻辩页为上一次 / 下一次 |
| 上一环节 / 下一环节 | `↑` / `↓` | |
| 减 / 加 10 秒 | `-` / `=` | |
| 重置本段 | `R` | **需按两次确认**，防误触 |
| 切换发言方 | `S` | 自由辩论 / 攻辩页有效 |
| 投影副屏 / 全屏 / 帮助 | `P` / `F` / `H` | |

输入框聚焦、设置抽屉打开、弹窗或新手引导显示时自动不响应；同一键位重复分配会提示占用。

### 配置存档

- 把调好的一套配置（队名、辩题、环节设置与时长、校徽，可选背景字体表盘铃声快捷键等外观偏好）存成快照随时还原，避免换赛制时反复重调。
- 支持存为新存档、载入、改名、删除，均有二次确认；列表实时显示每条占用体积与总占用，存储满时友好提示。载入后自动跳到首个环节首段但不自动开始计时。
- **导出 / 导入**：导出为 JSON 文件（可导出全部或单条），导入时逐层校验格式，非法文件、损坏条目、非本应用文件均明确提示且不写入脏数据；部分损坏时跳过坏条目继续导入可用项，同名存档自动加「(2)」后缀。含自定义铃声的存档在列表与文件名中均标注，便于换电脑。

### 引导与帮助

- **首次进入欢迎弹窗**：列出本次更新的全部要点，并提供「开始新手引导 / 查看更新日志 / 跳过」三个入口；看完日志可返回欢迎窗。
- 新手引导：分步高亮介绍环节导航、计时操作、设置、投影副屏与帮助入口，光标准确定位，自适应宽屏 / 窄屏 / 字号缩放；「关于」中可重新查看。
- 页面问号「？」：点击查看当前页面的使用说明（普通计时页 / 攻辩页 / 自由辩论页 / 设置页各有对应文案）。
- **更新日志**：内置全部历史版本，离线可读，可折叠展开。
- **检查更新**：读取 GitHub 发行版比对版本号，**点击即查（无时间间隔）**，5 秒超时，五种结果分别提示，tag 写法容错。
- 关于：版本与作者信息、开源链接、开发者邮箱、更新日志与检查更新入口、重新查看新手引导、MIT 许可信息。

### 工程特性

- **单文件**：整个应用只有一个 `index.html`，零第三方依赖、零构建步骤，拷到 U 盘即可用。
- 设置与校徽存于浏览器 `localStorage`（键 `debate-timer-settings-v1`），不上传任何数据。
- **唯一联网请求**是「检查更新」访问 `api.github.com`（`file://` 下 CORS 放行）；`github.com` 网页与 `raw.githubusercontent.com` 在 `file://` 下均被 CORS 拦截，不可用于取数据。
- 触控友好：按钮不小于 44px，375px 手机窄屏无横向溢出。
- 所有界面文字均为系统自带字体栈，无 emoji、无外部资源。

## 赛制流程（三人制默认预设）

| 环节 | 顺序与时长 | 黄灯提醒 |
| --- | --- | --- |
| 开篇立论 | 正方一辩 3:00 → 反方一辩 3:00 | 剩余 30 秒 |
| 攻辩 | 两轮四次，共 10 分钟：正二提问（正攻 1:00 / 反辩 1:30）→ 反二提问（反攻 1:00 / 正辩 1:30）→ 正三提问（正攻 1:00 / 反辩 1:30）→ 反三提问（反攻 1:00 / 反辩 1:30） | 剩余 15 秒 |
| 攻辩小结 | 正方一辩 1:30 → 反方一辩 1:30 | 剩余 60 秒 |
| 自由辩论 | 双方各累计 5:00，从反方开始，分开计时 | 到点亮红灯 |
| 结辩陈词 | 反方三辩 4:00 → 正方三辩 4:00 | 剩余 30 秒 |

> 攻辩中提问方（攻）先发言，被提问方可自行确定二辩或三辩应对；计时页只显示「正方应对 / 反方应对」。
>
> 全部时长与黄灯时点均可在「设置 → 环节时长」或「环节管理」中修改，也可整套换成自定义环节结构。

## 快速开始

### 电脑端

1. 用 Chrome / Edge 打开 `index.html`，即为主控界面。
2. 点击顶栏齿轮展开工具栏，点「投影副屏」弹出投影窗口（地址自动带 `?projector=1`），按窗口里的说明把它拖到投影仪或外接屏，点击画面进全屏。
3. 主控上一切操作（开始、切段、改设置、换校徽）投影实时跟随。

### 摆放与全屏

1. 主控点顶栏「投影副屏」，会弹出一个副屏窗口；首次打开默认显示一次摆放说明（可在设置中关闭）。
2. 把这个窗口拖到接了投影仪的那块屏幕（同一台电脑的第二个显示器直接拖过去）。
3. 点击副屏画面任意位置进入全屏，或按 `F11`；按 `Esc` 退出。

> 副屏页没有任何操作按钮，只负责展示；全部操作都在主控上做，改设置、换校徽、切换环节都会实时跟随。

### 关于跨设备（重要）

**副屏必须与主控来自同一台电脑的同一个浏览器**，不支持「手机当主控 + 电脑当投影」这类跨设备用法。

原因是本工具坚持**完全离线、零依赖、不上传任何数据**：主控与副屏之间只通过浏览器内置的
`BroadcastChannel` 与 `localStorage` 通信，这两条通道都只能在同一个浏览器实例内通信，出不了本机。

如果副屏长时间显示「等待控制端连接」，几乎都是因为它是在另一台设备或另一个浏览器中打开的
（副屏与主控不在同一浏览器时无法接收信号，跨设备时同样如此）。请把副屏窗口从主控的
「投影副屏」按钮重新打开。

## 操作说明

| 区域 | 功能 |
| --- | --- |
| 顶栏 | 正反方队名（含校徽）、工具栏展开齿轮（投影副屏 / 全屏 / 帮助「？」 / 关于「ⓘ」 / 设置） |
| 环节导航 | 五个环节的 Tab，点击切换；攻辩下方有四次轮次条 |
| 计时卡片 | 当前段信息、倒计时表盘 |
| 底部控制条 | 上一段（次）/ 开始暂停 / 下一段（次）/ ±10 秒微调 / 切换发言方 / 重置。三个环节控制条结构一致，第二行均为「−10 秒 / 切换发言方 / +10 秒」，重置单独一行 |
| 设置抽屉 | 十个分组 + 底部「恢复默认设置」与「保存并应用」 |

### 设置说明

设置抽屉顶部提供**搜索框**（输入即过滤、命中分组自动展开、关键词高亮、无结果提示）与**分组简称标签行**（点标签直接跳转并展开对应分组，并记住上次查看的分组）。

十个分组依次为：

1. **辩题与队伍** —— 正方 / 反方辩题（各 60 字上限）、队伍名称（上限 12 字）。某一方辩题留空则只显示其队名，双方都留空则整块隐藏；
2. **高校校徽** —— 正反方各上传一枚（建议正方形或透明底 PNG），自动居中裁剪压缩为 128px 圆形，主控与投影全部展示位同步；未上传时不显示占位图案；
3. **环节管理** —— 增删环节与小节、改名、启停、上下移动、恢复默认环节；每个小环节可选 1 个钟或 2 个钟并填时长；每个计时器各有一个黄灯开关；
4. **环节时长** —— 各环节时长（分:秒）与黄灯时点；四个黄灯项各带一个「启用」开关，关掉后该环节只在时间到时亮红灯；
5. **背景与字体外观** —— 背景主题、自定义背景管理、界面字体、界面字号、主控表盘样式、主控数字字形、主控数字格式、主控数字颜色；
6. **提示音** —— 声音总开关、黄灯 / 红灯开关、响铃次数、响铃间隔、铃声类型与音量、自定义铃声上传与试听、手机震动；
7. **操作与赛场** —— 自动进入下一段、屏幕常亮；
8. **配置存档** —— 存为新存档、载入、改名、删除、导出 / 导入；
9. **布局与投影** —— 投影元素显隐（七项）、投影布局预设（横向 / 纵向 / 自由）、投影表盘样式、投影数字字形、投影数字格式、投影计时颜色、摆放说明开关、重置自由布局位置；**投影尺寸**分为**单表盘组**（数字 / 表盘 / 顶部环节名 / 状态文字 / 队名）与**双表盘组**（数字 / 表盘 / 状态文字 / 两表盘间距 / 顶部环节名）共 10 个滑块，两组互不影响，拖动即时生效并同步副屏；
10. **键盘快捷键** —— 总开关 + 12 项逐项改键 / 清除 / 恢复默认。

**恢复默认设置**位于抽屉底部，点击后弹出勾选式弹窗，**九项全部可选、默认全不勾选**：

> 队名 · 辩题 · 校徽 ｜ 环节与时长 ｜ 赛场操作 ｜ 外观 ｜ 布局与投影 ｜ 提示音 ｜ 快捷键 ｜ 配置存档（会清空） ｜ 自定义环节结构（会清空）

弹窗标题栏右侧提供「全选」与「清空勾选」按钮。带「会清空」警示的两项即使勾选也会二次确认；未勾选的部分完整保留。

## 技术说明

- 原生 HTML / CSS / JavaScript（严格模式 IIFE），无任何框架、无 `type="module"`、无外部库与第三方依赖。
- 计时核心：`state.endAt = Date.now() + remain`，主循环用 `requestAnimationFrame` + 时间戳差值，抗后台漂移。
- 主控与投影同步：`BroadcastChannel` + `storage` 事件双通道 + localStorage 快照兜底。
- **同步范围限制**：上述通道均为浏览器进程内通信，因此副屏只能与主控在同一台电脑的同一浏览器内使用；这是零依赖、无上传设计的必然取舍。
- 设置持久化：`localStorage`（键 `debate-timer-settings-v1`）；自定义背景图片存 IndexedDB 或外部文件，设置里只存指针。
- 校徽处理：Canvas 居中裁正方形 → 压缩至 128px → dataURL 内联。
- 系统铃声：Web Audio Oscillator 合成音序，无音频文件；自定义铃声以 dataURL 存入 localStorage（≤500KB）。
- 投影窗口识别：URL 参数 `?projector=1`。
- 版本号唯一真相源为 JS 中的 `APP_VER`，页面显示位置与更新日志首条均由此回填，并有静态校验兜底。
